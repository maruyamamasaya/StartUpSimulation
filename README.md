# Formula Company

背景シグナルと会社の状態を読み、4つの経営レバーを調整して5年間・20四半期を経営する、ローカルブラウザ向け経営シミュレーションです。運は結果を揺らしますが、状況に合った判断ほど有利な範囲から結果が選ばれます。

## 起動

Node.js 20以上で次を実行し、`http://localhost:4173`を開きます。

```sh
npm start
```

外部パッケージ、データベース、外部APIは使いません。状態はメモリ上だけにあり、リロードまたは画面内のリスタートで初期化されます。

## 遊び方

1. 市場シグナルと現在の会社状態を読む。
2. 商品価格、広告費、採用人数、開発投資をクリックで調整する。
3. 「EXECUTE QUARTER」を押し、顧客・利益・満足度と四半期分析を確認する。
4. 資金難ではCRISIS MODEの緊急融資も検討しながら、5年後の企業価値1億円を目指す。

## 検証

```sh
npm test
npm run check
```
