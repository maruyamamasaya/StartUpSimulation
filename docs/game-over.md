# GAME OVER

失敗には原則としてBOARD WARNINGが先に表示され、次の四半期に立て直す機会があります。極端な資金ショートだけは即時終了することがあります。

- **BANKRUPTCY**: 資金ショート。
- **MARKET DEFEAT**: 低い市場シェアと顧客減少が続いた状態。
- **BUSINESS COLLAPSE**: 満足度と商品力が同時に崩れた状態。
- **FAILED TURNAROUND**: CRISIS MODE後も赤字を改善できない状態。
- **TIME LIMIT FAILURE**: 長期低迷、または期限までに持続可能な基盤へ届かなかった状態。

最終レポートのBEST DECISION、WORST DECISION、TURNING POINTを見て、次の会社で何を早く変えるべきだったか考えてみましょう。
