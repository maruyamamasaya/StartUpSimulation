# 攻略のカギ

## MARKET SIGNALだけを見ない
市場の追い風でも、人員や現金が足りなければ成長が負担になることがあります。

## ボトルネックを探す
顧客、商品力、社員、現金、ブランド。均等投資ではなく、今いちばん成長を止めているものを考えましょう。

## 現在と未来を分ける
広告は現在、開発と採用は未来に影響します。

## 役員の意見が割れたときが重要
対立は失敗の予告ではなく、異なる価値のトレードオフです。

## 因果関係を読む

```
顧客急増 → 人員不足 → 満足度低下 → 解約増加
```

同じ戦略を繰り返すより、現在の市場・競合・自社に合わせて考えてください。

## 事業ごとに経営の常識が違う
広告が強い事業もあれば、人材や商品力が成長上限になる事業もあります。

## 生存条件を意識する
急成長していても、現金が尽きれば終了します。成長速度と支払能力は別々に見ます。

## 衰退の前兆を組み合わせて読む
市場シェア、顧客、利益、現金、満足度の悪化を単独ではなく、組み合わせて判断しましょう。
