# 攻略のカギ

## MARKET SIGNALだけを見ない
市場の追い風でも、人員や現金が足りなければ成長が負担になることがあります。

## ボトルネックを探す
顧客、商品力、社員、現金、ブランド。均等投資ではなく、今いちばん成長を止めているものを考えましょう。

## 現在と未来を分ける
広告は現在、開発と採用は未来に影響します。

## 役員の意見が割れたときが重要
対立は失敗の予告ではなく、異なる価値のトレードオフです。

## 因果関係を読む

```
顧客急増 → 人員不足 → 満足度低下 → 解約増加
```

同じ戦略を繰り返すより、現在の市場・競合・自社に合わせて考えてください。
