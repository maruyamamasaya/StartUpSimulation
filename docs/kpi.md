# KPI

## 基本指標

- **Revenue / 売上**: 顧客から得た金額。売上と利益は同じではありません。
- **Profit / 利益**: 売上から広告、人件費、開発などを差し引いた残り。
- **Cash / 現金**: 今使える資金。経営の継続可能性を示します。
- **Customers / 顧客**: 会社を利用する顧客数。
- **Satisfaction / 満足度**: 顧客体験の指標。解約とも関係します。
- **Brand / ブランド**: 長期的な信頼・選ばれやすさ。
- **Development / 開発力**: 商品改善を支える力。

## 成長後に見える指標

- **Market Share / 市場シェア**: 市場全体の中で自社が持つ割合。
- **Churn / 解約率**: 顧客が離れる割合。
- **CAC**: 広告費を新規顧客数で見た、獲得コストの目安。

ひとつのKPIだけで判断せず、つながりを見ましょう。
