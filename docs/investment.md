# 投資と時間差

**すべての投資が今期の結果になるわけではありません。**

- 広告は短期の顧客獲得に効きやすい施策です。
- 採用は将来の運営余力につながります。
- 開発投資は、将来の商品力や顧客体験へ影響します。

## PENDING EFFECTS
ここには、まだ結果に表れていない採用・開発投資と、効果開始予定が表示されます。今期の利益が低くても、その判断が悪かったとは限りません。現在と数四半期先を分けて考えましょう。

```
開発投資 → 短期利益の低下 → 商品力・満足度 → 解約の抑制 → 長期売上
```

## 中長期プロジェクト

通常の四半期施策とは別に、複数四半期かけて進めるプロジェクトを1件開始できます。費用は開始時に全額支払い、四半期終了ごとに進行します。完了するまで効果は発生せず、途中キャンセルやランダム失敗はありません。プロジェクトごとの費用・期間・効果は開始画面で確認できます。
