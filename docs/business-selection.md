# 事業を選ぶ

事業によって、顧客・単価・市場・人員の規模や、投資の効き方が変わります。内部の難易度や倍率は表示されません。説明とKEY FACTORSから、その事業らしい経営を考えてください。

- **SaaS**: 継続課金型の法人サービス。商品開発と顧客維持を重視します。
- **EC / D2C**: 自社商品のオンライン販売。広告、ブランド、利益のバランスが中心です。
- **MOBILE APP**: 低単価・大量ユーザー型。口コミと規模が成長を動かします。
- **RESTAURANT**: 地域密着の飲食事業。人員、運営、満足度が重要です。
- **MANUFACTURING**: 投資が重い製造業。品質と長い時間軸を考えます。
- **CONSULTING**: 高単価の専門サービス。人材と信頼が成長上限になります。
- **GAME STUDIO**: 開発期間が長いコンテンツ事業。商品と資金余力を見ます。
- **FINTECH**: 信頼と品質が必要な金融サービス。崩れた顧客体験の影響が大きい事業です。
- **EDUCATION**: 学習成果と口コミが継続を生みます。人材と商品力の両方が必要です。
- **MARKETPLACE**: 二者をつなぐプラットフォーム。初期の壁を越えると規模が力になります。

別の事業で成功した配分が、そのまま通用するとは限りません。
