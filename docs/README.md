- 判断に迷う → [経営のヒント](tips.md)
- 市場を読む → [MARKET SIGNAL](market-signal.md)
- 一歩先を考える → [攻略のカギ](strategy-guide.md)

これは答え合わせではなく、会社を動かす因果関係を見つけるためのガイドです。
